# Dolphin Connect — Windows client

Dolphin Connect («دلفین کانکت») is Dolphin's remote-support client. Customers download it from
<https://support.dolphindev.ir>; a Dolphin technician connects only after the customer accepts.

This repository is the complete source of every build we ship, under the GNU Affero General Public
License v3.0 (`LICENCE`). Copyright notices of the original authors are kept in the source files.

- How it is built and what differs from the code it is based on: [`dolphin/README.md`](dolphin/README.md).
- Builds run in GitHub Actions (**Dolphin build**); releases carry `SHA256SUMS`.
